# Security policy

DutyBoard holds staff names, mobile numbers, and schedules for public safety agencies. Please report security problems privately so they can be fixed before they're public.

## Reporting a vulnerability

Use GitHub's private reporting: go to the **Security** tab of this repository and choose **Report a vulnerability**. Don't open a public issue.

Include what you found, how to reproduce it, and what someone could do with it. You'll get a reply acknowledging the report, and updates until it's resolved.

## Supported versions

Until the first release, only the `main` branch is supported. After that, security fixes go to the latest release.

## What's in scope

Problems in DutyBoard's own code and its default configuration, such as signing in as someone else, seeing or changing data your role shouldn't reach, sending texts without permission, or exposing secrets.

Problems in an agency's own server setup, or in third-party services like the texting provider, should be reported to whoever runs them.
